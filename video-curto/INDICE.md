# Índice (leia este primeiro)

Pasta de conhecimento para criar vídeos curtos que prendem atenção. Abra só o arquivo que a tarefa pedir.

- `metodo.md`: passo a passo para criar um roteiro.
- `hipoteses.md`: o que a pesquisa sugere, marcado como "para testar", com fonte e data.
- `ciencia-atencao.md`: estudos de psicologia e neurociência sobre atenção, curiosidade e memória (não são de rede social), com limites de cada um.
- `fontes/`: PDFs dos estudos enviados (Loewenstein 1994, Kang 2009, Shin e Kim 2019, Ghibellini e Meier 2025, reportagem sobre Nguyen 2025). Só abrir se precisar conferir o texto original; o resumo do que foi lido está em `ciencia-atencao.md`.
- `registro-testes.md`: o que aconteceu nos vídeos publicados (dados próprios). Fonte mais confiável.

Regra: depois de cada vídeo publicado, atualizar `registro-testes.md`. Quando uma hipótese for confirmada ou derrubada, atualizar `hipoteses.md`.
